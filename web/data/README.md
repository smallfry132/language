# Stroke data

`strokes-zh.json` holds the stroke outlines (`s`) and stroke centre lines (`m`) of the characters in the
HSK 1–3 word lists, taken unchanged from [hanzi-writer-data](https://github.com/chanind/hanzi-writer-data)
2.0.1, which is derived from [Make Me a Hanzi](https://github.com/skishore/makemeahanzi) and the
Arphic PL fonts. It is distributed under the Arphic Public License, see `ARPHICPL.TXT` (kept unaltered).
Coordinates are in a 1024 × 1024 box with the y axis pointing up (baseline at 900).
